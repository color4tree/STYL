## 1. 目标与已确认需求

帮助负责人了解公开页面何时被使用、大致国家／市场与来源分布、
商品兴趣、购物操作、主动使用时长估计和概略使用问题。
报告的是**次数**，不是人数，也不重建个人浏览过程。
提供受保护的后台统计和汇总日报邮件。

## 3. 范围与明确禁止项

第一方浏览器采集器只有在配置请求成功、
确认已启用且模式为 `aggregate-only`，并且没有退出偏好或适用排除项时，
才能自动启动。配置缺失、不兼容或不可用时，不能回退到带标识追踪。

服务器立即把接受的数值累加到私有存储中的小时桶和独立的概略维度。
新采集不建立持久化原始事件暂存表、会话表、事件待发送表、
导航历史或个人路径记录。新模式报表不读取旧会话／事件历史或旧汇总，
也不把它们重新包装成新汇总报表。

禁止创建、发送或保留分析用途的浏览器／会话标识、Cookie、
localStorage 标识、事件 UUID、页面浏览 UUID 或请求关联 ID。
不持久化原始请求／发生时间、原始 IP、完整网址、查询参数、
来源网站域名、原始 User-Agent、客户表单正文／联系方式、私有商品字段，
或可形成指纹的多维组合记录。
不做会话回放、键盘／鼠标轨迹记录、身份匹配、跨站追踪或第三方分析标签。

不用于识别身份的布尔退出偏好，以及现有内部访问排除偏好，是偏好而不是访客标识。
必要购物车和管理员状态有各自用途，本次修改不能删除或挪用它们。

## 4. 统计口径

| 指标 | 必须采用的定义 |
| --- | --- |
| 时间桶 | 以服务器接收小时为准，保存 UTC 小时边界；不保存客户端／服务器原始事件时间戳 |
| 页面浏览 | 实际显示的公开页面进入，包括真正的 SPA 页面导航；不含预加载、初始化绑定、RSC／API／媒体请求或重复渲染 |
| 页面内导航 | 用户主动执行的允许清单内锚点／导航操作，与页面浏览分开 |
| 商品展示 | 商品名称／价格摘要至少 50% 连续可见一秒；仅用内存状态限制同一页面显示期间每件商品计一次 |
| 详情浏览 | 商品详情成功显示，不是网址请求或加载状态 |
| 展开 | 真实桌面端 Show more 操作；手机自动显示完整详情不算展开 |
| 购物车／询价操作 | 指定操作次数；购物车写入成功后才能记录成功操作 |
| 已保存询价 | 根据成功持久化的业务询价记录计数，不能从浏览器事件推断 |
| 询价邮件已接受 | SMTP 接受通知，不代表已进收件箱或已读 |

“商品类型 + 不可变商品 ID”识别的是**商品**，不是人或浏览实例。
报表可读取允许公开的商品名称，但不能暴露草稿／私有字段。
当前目录价格不是收入。

### 总主动使用时长估计：TA-001

- 页面可见、获得焦点，且最近 60 秒内有活动时才计时；
  信号不含实际输入内容。可见页面中的活跃视频可计入，
  后台播放不能证明用户在注意。
- 使用约 15 秒、有上限的时长增量。页面隐藏／空闲时暂停，
  避免本地同一时段重复计时，不根据很晚断线推断长时间停留。
  页面离开时的最后一次发送尽力而为。
- 只把累计时长和次数存入服务器接收小时，
  不保存时段起止时间、顺序或标签页标识。
- 可用不带身份标识的浏览器 Web Lock 协调，减少重叠时长增量；
  不能改为持久化标签页 ID 或租约标识。
- 展示**总估计活跃时长**，不提供中位数或每会话时长。
  不进行跨标签页／会话合并，也不能保证是某个人实际停留的总时间。
  应说明最后增量丢失、静止阅读低估及多标签页可能高估的限制；
  不能为纠正这些限制重新引入标识。

## 5. 事件数据约定

### 无关联标识的数据格式与独立维度：TA-002

只接受带版本、符合允许清单的事件名、规范路径类别、
必要固定属性、安全商品引用和有上限的数字增量。
浏览器事件对象只存在于容量受限的内存发送队列。
环境、小时和可信国家／币种由服务器确定，
不能以浏览器传来的国家、价格、时间或身份声明为准。

- 发送前将路径归为已知路径／模板；不发送完整网址、
  商品名称查询文本、片段或任意路径。
- 来源只保留固定类别，不发送／保存来源域名。
  推广活动只保留明确允许的代码，不保留任意 UTM 值或网址中的客户资料。
- 设备／浏览器使用概略类别，不保存完整 UA／屏幕／操作系统组合。
- 每种维度独立存储。例如“小时 + 来源类别”的页面浏览次数，
  和“小时 + 设备类别”的页面浏览次数分别保存；
  **不**保存“小时 + 国家 + 活动 + 设备 + 浏览器 + 商品”的组合历史。
- 每个分布只描述本维度的页面浏览次数。
  不能将其与商品／询价操作拼接以重建来源关联，
  也不能把不同维度相加，当作互不重叠的流量。
- 国家标签仅为 `US`、`CA`、`Unknown` 等国家值，
  不与币种组成国家／币种标签。
  每件商品的操作总数可按币种分组，但不能再与国家、来源、活动、
  设备或浏览器历史拼接。

### 操作清单：TA-003

| 事件／类别 | 必须采用的汇总方式 |
| --- | --- |
| `page_view` | 页面／小时总数，以及独立概略维度的页面浏览次数 |
| `navigation_click` | 固定导航／锚点操作计数，不保存前后路径轨迹 |
| `item_impression`、`item_detail_open`、`item_details_expand` | 按可见／显示／实际操作定义，分别计算每件商品的次数 |
| `media_open` | 主动打开媒体次数；仅安全商品／媒体类别，不含私有网址 |
| `cart_add`、`cart_quantity_change`、`cart_remove`、`cart_clear`、`cart_view` | 成功操作／页面显示分别计数；不保存购物车或会话快照 |
| `quote_open`、`quote_form_start`、`quote_submit_attempt` | 不相互关联的操作次数；直接可用时可带安全商品引用，不含字段值或关联令牌 |
| `quote_error`、`site_error` | 固定概略错误类别计数，不含异常正文、堆栈或请求数据 |
| `catalog_empty`、`item_unavailable` | 真实空／不可用结果计数，只带经过校验的公开背景 |
| `engagement` | 把有上限的时长累加到总估计值，不保留时段历史 |
| `web_vital` | 有上限的数值总和／样本数，用于算平均值；不保留原始样本或中位数 |

这些次数用于了解趋势，不是“每个访客恰好一次”的测量。
内存中的路径／展示抑制可避免常见重复渲染，不需要 UUID。
刷新后或网络发送结果不明确时，没有持久化标识可用于去重；
不要承诺本模式无法实现的重放检测。

### 独立业务询价计数：TA-004

无论分析被关闭、用户退出、请求被阻止或服务故障，
以及询价通知发送失败，已保存询价仍是权威业务记录。
独立统计业务记录，不发送／保存分析身份，
也不把询价 ID 与页面、商品、来源或活动历史关联。

不从客户私有留言推断商品，不把联系方式复制到分析。
原有纯文本询价客户端继续可用。
必要的业务去重按业务记录及其访问规则处理，不依赖浏览器分析令牌。
把**已保存询价（业务总数）**与询价操作次数分开标示。
不提供已关联／未关联会话总数，也不提供会话转化率。

为兼容旧客户端，新询价会忽略旧分析输入，不保存或分配任何归因；
这与分析采集接口拒绝带标识请求是两条不同规则。
本次不改写已有权威询价 JSON，历史 `analyticsAttribution` 字段
可保留到另行批准的清理执行时；新报表不得使用这些旧关联。

业务询价来源无法确认时，摘要中的询价值为 `null`（不可用）。
现有每日行响应格式仍要求数字，因此此时每天显示数值 `0`，
同时提供明确的**询价总数未确认**警告；
这个占位值不证明没有已保存询价。
使用报表的界面／导出必须保留并显示警告，不能把它当作已验证的零值。

## 6. 后台与解读方式

使用现有授权后台；今天／昨天／最近 7／30 天和自选日期，
均明确使用 **America/Los_Angeles（太平洋）** 时区，并手动刷新。

- 已保存询价是独立业务总数，不是被追踪访客的漏斗。

- 最近被统计活动只精确到**小时**，注明时区；
  报表生成时间是运行元数据，不是某个访客的精确活动时间。
  `coverage.trackingSince` 和 `coverage.lastEventAt`
  使用新模式独立的小时级元数据，不读取旧事件时间戳。
- 说明不可测指标和覆盖限制。零计数说明检查是否启用 aggregate-only、
  排除规则、日期范围、批次发送与刷新，不能要求顾客“接受分析”。

- CSV 和新报表快照只含汇总，按需要授权访问、限制范围，
  防止表格公式／HTML 注入。不包含流量标识、会话指标或旧报表内容。

### 不可用指标与对比：TA-006

独立／新／回访访客、会话、个人路径、进入／离开归因、
按会话的漏斗／流失／转化率、会话关联的活动／商品／询价来源，
以及中位数，在本模式下**不可测**。
不能从 IP、页面浏览总数或独立维度次数推算这些结果。

不同操作次数可以并列显示，但不能包装成按顺序跟踪同一群体的漏斗。
完整日期总数可与此前七个完整日期的日均值比较，
同时显示次数、覆盖限制和样本量。
零基准显示“没有可比基准”，不是无穷大。
不能据此推断原因、收入或流失销售；涉及业务金额时 CAD／USD 分开。

## 7. 隐私、偏好与保留期限：TA-007

临时使用可信服务器本地国家识别，不把原始 IP 写入分析。
即使未知国家的定价回退为 CAD，国家仍为未知。
不把 IP 发给外部定位服务。

普通 `/privacy` 页面应说明用途、汇总类别、自动统计、
保留期、退出方式、排除项、局限和联系渠道。
提供不识别身份的布尔退出设置，不显示打断式同意面板，
也不在前台显示“已开启／已关闭／正在连接”等技术采集状态。
不能隐藏告知，也不能声称第一方匿名汇总在所有地区都无需同意。

- **Turn off usage measurement（关闭使用统计）** /
  **Allow aggregate measurement（允许汇总统计）** 只修改
  `styl-analytics-exclude` 布尔偏好，不创建身份或同意／会话记录。
  此页面不是采集技术状态面板。
- 先把原先明确拒绝迁移为布尔退出偏好，再删除旧
  `styl-analytics-consent` 记录；偏好迁移或新配置不能悄悄覆盖拒绝。
- 清理旧的分析访客／会话／标签页租约键和已迁移的旧同意键，
  不清除迁移后的隐私／内部排除偏好、必要购物车或管理员凭据。
- 退出后停止采集、清空尚未发送队列；遵守 DNT／GPC、
  管理员、内部访问和已知机器人排除规则。
  无法安全读取隐私偏好时，停止采集，不能把读取失败当作授权。
- 新汇总中没有可按人提取／删除的个人历史。
  退出不代表能追溯删除某个人先前对汇总的贡献，
  应如实解释，不能编造删除成功回执。

不能宣称旧数据已经删除。上线前验证其维护路径，
或批准有明确范围的清理，不能因停用旧报表而无限期保留旧个人／假名数据。
恢复备份时，必须执行到期规则和之前已批准的删除决定。

分析维护任务按原有 30 天窗口清理旧原始事件／会话表，
旧汇总按 13 个自然月到期，但不会改写权威询价 JSON 或受保护的备份副本。
询价中历史 `analyticsAttribution` 字段及备份内容继续保持私有，
按单独批准的保留／清理流程处理，本次不暗中清除。

Caddy／Uvicorn／基础设施访问日志及业务询价／联系资料可能包含个人数据。
“只做匿名汇总”只描述新分析采集，
不是对整个网站或旧数据库／备份中每个文件的承诺。

## 8. 流量质量与可靠采集

### 排除与信任边界：TA-008

本地／测试／预发布／正式环境数据分开。
排除管理员页面、保存管理员凭据的标签页、明确内部访问、
DNT／GPC、已知机器人、监控和自动化。
不能为测试而关闭真实用户的隐私偏好。
分类并不完美；数据是尽力统计的操作，不是全部访问。

在服务器校验商品可见性与概略字段。
拒绝旧的带标识请求、未知字段和不安全元数据，不记录请求正文。
旧的 `POST /api/analytics/session` 返回 **410 Gone**，
不生成身份或兼容会话，也不回退到带标识采集。

`POST /api/analytics/events` 成功时只返回 `{accepted: number}`，
不返回事件 ID 或时间戳。
未知／非公开商品引用会使整个批次返回 **422**，
不能只拒绝部分事件却提交其他计数。

旧 `DELETE /api/analytics/session` 只为历史撤回保留，
不创建／恢复带标识采集，也不提供对新匿名汇总按人的删除。
保留此接口不代表旧数据已经清除。

### 发送与故障隔离：TA-009

- 第一方同源异步发送；限制结构、来源、频率、增量和队列有效期。
  每批最多 **20 个事件／16 KiB**，通常每 **15 秒**发送一次。
- 初次页面可以尽快发送以覆盖短访问，pagehide／beacon 尽力发送。
  待发送事件和本地抑制重复状态仅在内存，不写入浏览器持久化存储或原始事件表。
- **采集发送结果不明确时，不自动重试。**
  没有事件 ID，重放可能重复计数；
  宁可丢弃失败／不确定批次，也不引入持久化标识或声称“恰好一次”。
- 以接收小时而非客户端时钟归类；延迟发送可能进入后一个小时／日期。
  不为回填发生时间而保存精确时间戳。
- 分析中断、校验或存储失败不能影响导航、媒体、购物车和询价保存。
  运维看到清理后的错误；顾客不能收到误导性的购物失败，
  报表也不能把失败伪装成正常的零结果。

## 9. 每日摘要邮件

### 时间与收件人：TA-010

已批准时间仍为每天 **08:00 America/Los_Angeles**，
统计前一个本地自然日，使用 IANA 时区正确处理夏令时。
服务器持久化定时任务不依赖 VS Code 或聊天保持打开。
非正式环境禁止发送；正式环境也需要明确启用、
单独批准的内部分析收件人。**收件人尚未批准。**

可复用受保护的 SMTP，但不能继承询价收件人或更改客户 Reply-To。
只使用配置的业务回复地址和无凭据的后台链接。
预览不发送邮件。

2026-09-29 新增要求：后台 **Daily email settings（日邮件设置）**
可以开启／关闭日报，并配置最多 20 个收件地址，每行一个或用逗号分隔。
服务器验证邮箱格式，并忽略大小写去重。此界面已随 `e91f28a` 上线，
部署时真实邮件发送仍保持关闭，需管理员另行配置收件人并保存为开启。

设置保存在私有 SQLite 中，重启后保留；第一次保存后，以后台设置为准，
不再用环境变量覆盖。开启时至少需要一个收件人；关闭时可以保留或清空地址。
SMTP 密码／发件设置仍由服务器管理，询价通知不受影响。

只有已认证管理员可以读取／保存完整地址。旧版本保存返回 409，
不能悄悄覆盖其他管理员的修改；错误保留输入，放弃未保存修改后重新加载
需要确认。设置存储故障不能伪装成“已关闭”。预览、定时任务和手动重试
读取同一份设置。点击保存不立即发送邮件；正式环境启用后，下一次
15 分钟检查可能补发最近一期应发送日报。每个发送任务认领前再次检查
是否已关闭或删除收件人，但已在发送中的邮件无法撤回。
本地／测试／预发布环境即使保存为开启，也始终禁止真实发送。
设置随分析数据库备份，不进入目录恢复 ZIP，也不随 90 天发送记录清理而过期。

### 必含内容：TA-011

邮件与预览应简短、突出业务重点：

- 日期及太平洋时间；当天未结束的预览标明“Through HH:00”（截至该小时）。
- 页面浏览次数、前七天日均值；只有完整日期才显示增减百分比。
- 已保存询价、估算活跃时长（分钟／小时）、加入购物车及打开询价的次数。
- 最多三个热门商品，按加购、详情及曝光次数排序，保留市场币种。
- 最多三个国家与流量来源；无数据的明细段落不显示。
- 只有真实问题才显示 **Attention（需要关注）**：采集关闭、询价统计不可用、
  数据被拒绝或已记录错误。
- 进入完整后台报表的链接。

移除旧邮件里冗长的隐私／标识、保留期限、小时截止实现方式、
以及开始统计时间等说明，不再重复通用警告和技术观察。
这些说明仍保留在完整后台和运维文档中，不从底层报表删除。
HTML 邮件使用标题与简洁汇总表格，不再是大段等宽字体文本。
确实不可用的数据仍显示 N/A，不能伪装成零。

纯文本、HTML、CSV 和新快照中都不能出现访客／会话、
时长中位数、顺序漏斗、关联询价转化率、原始标识或个人路径。
例如写“页面浏览：<次数>；已保存询价（独立业务总数）：<数量>”，
不能写“<访客人数> 以 <比例> 转化”。

未来客服接入只提供获准的不关联个人的汇总，
不提供原文、联系方式或关联 ID。
基本客服不依赖分析；城市／邮编内容在另行批准前继续不显示。

### 时间区间、快照与失败：TA-012

- 采用包含起点、不包含终点的太平洋自然日区间，再转换为 UTC；
  正确处理 23／25 小时日期，不错误合并夏令时重复小时对应的 UTC 桶。
  当前仅支持 UTC 偏移为整小时的报表时区，包括太平洋夏令时。
  非整小时偏移的时区必须明确报错，不能四舍五入边界或悄悄错误统计小时桶。
- 邮件／预览排除**当前尚未完整结束的小时**。
  原来的“五分钟前截止”已被替代：
  只有小时汇总，无法证明分钟级完整性。
  显示完整小时边界；当前后台可含正在进行的小时，
  因而可能与有效区间更窄的邮件预览不同。
- 为收件人重试冻结只含汇总的快照，
  不能给新模式发送任务加载旧会话报表快照。
  生成／运行／发送时间是运维元数据，不是保留的浏览时间戳。
- 第 3 版邮件报表使用简洁的匿名汇总格式。
  旧版已经接受或发送结果不明确的记录，仍跨版本约束发送：
  即使不复用旧快照内容，也不能因更换格式就重新发给已接受的收件人，
  或绕过不确定发送的暂停核查状态。
- 持久化报表日期／时区／版本及每个收件人的发送状态，
  防止并发重复或重复发送给已经接受的收件人。
- SMTP 接受不等于进入收件箱。
  有限重试只用于明确的**邮件**失败，不适用于不确定的分析批次。
  不确定／中断发送交由操作人员核查，不能承诺邮件永远恰好一次。
- 真实零活动可发送简短已启用日报；生成失败不能假装正常零报告。
  通过失效 SMTP 之外的方式显示故障，不自动反复发送修正版。

## 阅读辅助：常用术语

本节仅帮助理解，不增加需求。

| 术语 | 通俗解释 |
| --- | --- |
| Aggregate-only / 只做汇总 | 立即累加次数／数值，不保存可关联的个人事件历史 |
| Hour bucket / 小时桶 | 同一服务器接收小时内的总计，不含原始发生时间 |
| Independent dimension / 独立维度 | 来源、设备等分别统计，不拼接成多属性个人记录 |
| Event / 事件 | 一次明确操作；本模式只在内存传递，持久化的是总计 |
| Session / 会话 | 一次可关联的访问过程；本模式不建立、不统计 |
| Funnel / 漏斗 | 按顺序追踪同一群体的多个阶段；本模式不提供会话漏斗 |
| Attribution / 归因 | 将询价与先前访问／来源关联；本模式不做会话关联 |
| Opt-out / 退出 | 停止后续测量的偏好，不是用于识别人或回删汇总的 ID |
| UTM | 营销网址参数；这里只能使用获准活动代码 |
| SMTP | 邮件发送协议；接受不等于已进收件箱 |
| UTC / IANA / DST | 统一时间基准／命名时区／夏令时 |
| WAL | 数据库预写日志；备份需保证数据库整体一致 |
| SPA / RSC / Hydration | 页面导航／组件数据请求／初始化交互；不能都算作新页面浏览 |
| BFCache | 浏览器前进／后退所用的页面状态缓存 |
